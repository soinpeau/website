# SOINPEAU Website V4

This version combines the stronger V2 visual/product direction with the official SOINPEAU company logo and favicon assets retained from V3.

## Files
- `index.html` – website structure
- `styles.css` – responsive premium pharmaceutical styling
- `script.js` – product search, therapy filtering, product modal, mobile navigation and reveal animations
- `logo.png` – official SOINPEAU logo retained unchanged
- `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png` – browser/site icons
- `assets/` – local product artwork extracted from the company presentation

## Run locally
Open `index.html` directly in a modern browser, or serve the folder with any static web server.

## Deployment
Suitable for Netlify, Vercel, GitHub Pages, cPanel/shared hosting, S3/static hosting, or a standard web server.

## Important
Before public launch, pharmaceutical claims, indications, dosages, and prescription-product content should receive appropriate medical/regulatory review for the intended market.
